# CareRisk 48H — Synthetic Evidence Explorer

本頁僅使用固定合成資料作研究展示；不提供個案風險、診斷、治療或照護決策。

Synthetic research demonstration only — not for clinical or care decisions.

This small portfolio interface illustrates how a research workflow can show or
withhold an explanation when fixed synthetic evidence is complete, incomplete,
structurally unavailable, or missing an authored source note. All four states
are pre-rendered teaching examples. The Space accepts no uploads or free-form
input and performs no prediction, training, evaluation, or remote data access.

## Public bundle boundary

The Docker Space contains only the application entry point, two small UI/content
modules, the exact runtime requirement, and its license and disclosure files.
It includes no research records, trained weights, generated outputs, or formal
evaluation evidence.
